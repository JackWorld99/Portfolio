# Jack Wong · Portfolio

Websites, apps and AI assistants for businesses in Malaysia.
Live at **https://wwj-portfolio.vercel.app**

## What's inside

A single static page: no build step, no server code, no third-party scripts.

- `public/index.html`: the page
- `public/styles.css`: styles (self-hosted Sora + Inter fonts)
- `public/app.js`: scroll reveals, count-ups and the live WhatsApp assistant demo (EN / 中文 / BM)
- `vercel.json`: serves `public/` and sets security headers (CSP, HSTS, no framing)

## Run locally

```bash
npx serve public
```
